مشروع مسابقات الابتكار الطلابية 2026-2027

طريقة الرفع إلى GitHub Pages:
1. فك ضغط الملف.
2. ارفع محتويات مجلد innovation-competitions إلى المستودع (وليس المجلد الخارجي فقط).
3. تأكد أن index.html في جذر المستودع.
4. من Settings > Pages اختر Deploy from a branch ثم main و /root.
5. احفظ وانتظر نشر الموقع.

الملف يعمل دون بناء أو تثبيت مكتبات.
